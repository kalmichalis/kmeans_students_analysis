# 📊 Ανάλυση Φοιτητών με K-Means Clustering

## 📌 Πλαίσιο Project

Τα δεδομένα που χρησιμοποιούνται είναι εκπαιδευτικού χαρακτήρα και αφορούν την επίδοση φοιτητών σε υποχρεωτικές και προαιρετικές εργασίες καθώς και στην τελική και επαναληπτική εξέταση.
Το project αυτό χρησιμοποιεί τον αλγόριθμο K-Means Clustering για την ομαδοποίηση φοιτητών με βάση την επίδοσή τους σε εργασίες και την τελική/επαναληπτική εξέταση.

Στόχος είναι η ανάλυση της συμπεριφοράς των φοιτητών και η ανακάλυψη ομάδων με παρόμοια χαρακτηριστικά.

## 🎛️ Είσοδος Χρήστη

Το πρόγραμμα δίνει τη δυνατότητα στον χρήστη να εισάγει παραμέτρους μέσω πληκτρολογίου, καθιστώντας την ανάλυση δυναμική.

Συγκεκριμένα, ο χρήστης μπορεί να επιλέξει:

- τον αριθμό των clusters (k)
- αν θα χρησιμοποιηθούν οι προαιρετικές εργασίες
- αν θα χρησιμοποιηθεί η τελική ή η επαναληπτική εξέταση ως αναφορά

Με αυτόν τον τρόπο, το ίδιο dataset μπορεί να αναλυθεί με διαφορετικούς τρόπους, ανάλογα με τις επιλογές του χρήστη.

- 4 υποχρεωτικές εργασίες

- 10 προαιρετικές δραστηριότητες
- Τελική εξέταση
- Επαναλαπτική εξέταση

Συνολικά: 22 χαρακτηριστικά (features)

Κάθε γραμμή αντιστοιχεί σε έναν φοιτητή.

## 🧠 Αλγόριθμος

Χρησιμοποιείται ο K-Means Clustering από τη βιβλιοθήκη scikit-learn.

## ⚙️ Παράμετροι K-Means

- **Αριθμός clusters (k):**  
  Ορίζεται από τον χρήστη και καθορίζει σε πόσες ομάδες θα χωριστούν τα δεδομένα.  
  Για παράδειγμα, k=3 σημαίνει ότι οι φοιτητές θα ομαδοποιηθούν σε 3 διαφορετικά clusters.

- **random_state=42:**  
  Χρησιμοποιείται για την εξασφάλιση αναπαραγωγιμότητας των αποτελεσμάτων.  
  Δηλαδή, κάθε φορά που τρέχει ο αλγόριθμος με τα ίδια δεδομένα, παράγει τα ίδια clusters.

- **n_init=10:**  
  Ο αλγόριθμος εκτελείται 10 φορές με διαφορετικές αρχικοποιήσεις κέντρων (centroids).  
  Στη συνέχεια επιλέγεται το καλύτερο αποτέλεσμα (με τη μικρότερη συνολική απόσταση).

## ⚙️ Προεπεξεργασία Δεδομένων

Η προεπεξεργασία των δεδομένων είναι ένα κρίσιμο στάδιο πριν την εφαρμογή του αλγορίθμου K-Means, καθώς εξασφαλίζει την ποιότητα και την ομοιομορφία των δεδομένων.

- **Καθαρισμός δεδομένων:**  
  Στο αρχικό dataset υπήρχαν τιμές που αντιπροσωπεύουν ελλείψεις δεδομένων, όπως NaN, "-", "-1" ή κενά πεδία.  
  Αυτές οι τιμές υποδηλώνουν περιπτώσεις όπου ο φοιτητής δεν παρέδωσε εργασία ή δεν συμμετείχε σε εξέταση.

- **Αντικατάσταση ελλειπουσών τιμών:**  
  Οι μη έγκυρες/ελλείπουσες τιμές αντικαταστάθηκαν με NaN και στη συνέχεια συμπληρώθηκαν με τον μέσο όρο της αντίστοιχης στήλης (mean imputation), ώστε να διατηρηθεί η συνοχή των δεδομένων.
  Η επιλογή αυτή διατηρεί το σύνολο των δεδομένων, ωστόσο μπορεί να μειώσει την πληροφορία που σχετίζεται με την πραγματική απουσία ή μη παράδοση εργασιών.

- **Μετατροπή δεδομένων:**  
  Όλες οι τιμές μετατράπηκαν σε αριθμητικούς τύπους (float), καθώς ο αλγόριθμος K-Means απαιτεί αριθμητικά δεδομένα για τον υπολογισμό αποστάσεων.

- **Κανονικοποίηση (Standardization - Z-score):**  
  Εφαρμόστηκε κανονικοποίηση των χαρακτηριστικών ώστε όλα τα δεδομένα να έχουν:
  - μέσο όρο = 0  
  - τυπική απόκλιση = 1  

  Αυτό είναι απαραίτητο διότι ο K-Means βασίζεται σε αποστάσεις και διαφορετικές κλίμακες θα επηρέαζαν άδικα τα αποτελέσματα.

## 📊 1. Κανονικοποίηση Δεδομένων (Z-score)

Η κανονικοποίηση Z-score χρησιμοποιείται ώστε όλα τα δεδομένα να μπουν στην ίδια κλίμακα. Αυτό είναι σημαντικό γιατί στον K-Means οι αποστάσεις παίζουν τον βασικό ρόλο και αν κάποια χαρακτηριστικά έχουν μεγαλύτερες τιμές, επηρεάζουν περισσότερο το αποτέλεσμα.

Ο τύπος είναι:

z = (x - μ) / σ

όπου:
- x είναι η αρχική τιμή
- μ είναι ο μέσος όρος της στήλης
- σ είναι η τυπική απόκλιση

Με απλά λόγια, το Z-score μας λέει πόσο μακριά είναι μια τιμή από τον μέσο όρο.

Αν το z είναι κοντά στο 0, σημαίνει ότι η τιμή είναι “κοντά στο φυσιολογικό”.  
Αν είναι θετικό, είναι πάνω από τον μέσο όρο, ενώ αν είναι αρνητικό, είναι κάτω από τον μέσο όρο.

Στο project αυτό η κανονικοποίηση είναι απαραίτητη γιατί οι εργασίες έχουν διαφορετικές τιμές και χωρίς αυτήν ο αλγόριθμος θα έδινε μεγαλύτερη σημασία σε κάποιες στήλες απ’ ό,τι σε άλλες.

---

## 📈 2. Συντελεστής Συσχέτισης Pearson

Ο Pearson δείχνει αν δύο μεταβλητές “πηγαίνουν μαζί”, δηλαδή αν όταν αυξάνεται η μία, αυξάνεται ή μειώνεται και η άλλη.

Ο τύπος είναι:

r = Σ (x - x̄)(y - ȳ) / √[ Σ (x - x̄)² · Σ (y - ȳ)² ]

όπου:
- x και y είναι οι δύο μεταβλητές
- x̄ και ȳ είναι οι μέσοι όροι τους

Η τιμή του r μπορεί να είναι από -1 έως 1:
- 1 σημαίνει ότι οι δύο μεταβλητές αυξάνονται μαζί
- 0 σημαίνει ότι δεν υπάρχει σχέση
- -1 σημαίνει ότι όταν η μία αυξάνεται, η άλλη μειώνεται

Στο project αυτό χρησιμοποιήθηκε για να δούμε αν υπάρχει σχέση ανάμεσα στον μέσο όρο των εργασιών και στην τελική εξέταση.

Το αποτέλεσμα που βγήκε είναι κοντά στο 0, άρα πρακτικά δεν φαίνεται να υπάρχει ισχυρή γραμμική σχέση μεταξύ τους.


## 📊 Αποτελέσματα

Ο αλγόριθμος K-Means εφαρμόστηκε με αριθμό clusters k=3, επιλογή που έγινε ώστε να υπάρχει μια απλή και κατανοητή ομαδοποίηση των φοιτητών σε τρία βασικά προφίλ (υψηλής, μέτριας και χαμηλής επίδοσης).

Η επιλογή του k=3 θεωρείται λογική για το συγκεκριμένο πρόβλημα, καθώς επιτρέπει μια φυσική ερμηνεία των αποτελεσμάτων χωρίς υπερβολική πολυπλοκότητα, ενώ ταυτόχρονα αποφεύγει την υπεραπλούστευση με πολύ λίγα clusters.

Επιπλέον, στο clustering χρησιμοποιήθηκαν όλες οι διαθέσιμες δραστηριότητες (υποχρεωτικές και προαιρετικές σύνολο 22), ώστε να αποτυπωθεί όσο το δυνατόν πιο ολοκληρωμένα η συνολική συμμετοχή και προσπάθεια κάθε φοιτητή.

Ως αναφορά (label), χρησιμοποιήθηκε η τελική εξέταση (όχι η επαναληπτική), καθώς η τελική εξέταση αποτελεί την κύρια και πιο αντιπροσωπευτική αξιολόγηση της επίδοσης των φοιτητών στο μάθημα.
